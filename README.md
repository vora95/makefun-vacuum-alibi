A small program that writes one short text (114 characters) to `/output/entry.txt`: the excuse a robot vacuum gives for missing a spot — its lidar detected a sock, classified it as a sleeping pet, and it is not a monster.

> I skipped that spot on purpose: my lidar detected a sock, classified it as a sleeping pet, and I am not a monster.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
